## Get started

```bash
cargo add reqsign --no-default-features --features aws-bearer
```

Set `AWS_BEARER_TOKEN_BEDROCK` to your Amazon Bedrock API key, then select
`bedrock` as the AWS signing name.

```rust
use reqsign::{Context, OsEnv};
use reqsign::aws::bearer;

let ctx = Context::new().with_env(OsEnv);
let signer = bearer::default_signer(ctx, "bedrock")?;
let mut req = http::Request::post(
    "https://bedrock-runtime.us-west-2.amazonaws.com/model/example-model/invoke",
)
.body(())?
.into_parts()
.0;
signer.sign(&mut req, None).await?;
```

To supply the token directly, construct a `Signer` with
`bearer::StaticCredentialProvider::new(token)?` and `bearer::RequestSigner`.
Both sources provide opaque tokens. When a token changes, create a new signer
or call `with_credential_provider` to start with an empty credential cache.
