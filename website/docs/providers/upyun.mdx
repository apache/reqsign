## Get started

```bash
cargo add reqsign --features upyun
```

```rust
use reqsign::upyun::StaticCredentialProvider;
use reqsign::{default_context, upyun};

let ctx = default_context();
let signer = upyun::default_signer(ctx)
    .with_credential_provider(StaticCredentialProvider::new("operator", "password"));

// Build the request and choose the bucket endpoint in the caller.
let mut req = http::Request::put("https://v0.api.upyun.com/bucket/object.txt")
    .body(())?
    .into_parts()
    .0;

signer.sign(&mut req, None).await?;
```

The default chain reads the active session from the Upyun CLI (`upx`)
configuration at `~/.upx.cfg`. Install `StaticCredentialProvider` directly, or
push it in front of the default chain, when credentials come from application
configuration.

The signer adds `Date` and `Authorization`. Set `Content-MD5` before signing
when the request body should participate in the signature. It does not create
presigned URLs or token credentials, and it does not send the request.
